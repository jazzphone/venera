Restart to start Venera

After the restart, open Venera in Applications to see what runs: the desktop on Metal, hardware video, and whether Safari's WebGL can use the GPU. It asks to send notifications so it can tell you when something needs you.

When this Mac's security settings had to change first (SIP and AMFI, in OpenCore), they start at this restart: Venera then finishes installing by itself (a minute or two) and restarts once more, asking first if you're logged in.

What the installer did is in /Library/Application Support/Venera/install.log. Status in Terminal: sudo "/Library/Application Support/Venera/status.sh".
